开启与关闭的实际差异

到会话记录查看每轮真实轨迹
关闭 MCP本地 Mock
  1. MCP Server 不发起任何网络请求
  2. 订单创建、列表、详情和退单读取本地数据
  3. 订单来源标记为“本地 Mock”
开启 MCP客户工具链
  1. 依次调用 authorizeMember、previewOrder、createOrder
  2. 请求携带用户 Header，并使用下方能力映射
  3. 技术故障时记录原因并自动转本地兜底
本地契约基准 客户 PDF 8 个主工具 · camelCase · Header 身份 · 先授权再调用 · SKU 全链路 手机号 RSA、真实网关鉴权和 SSE 响应流需在客户正式环境验证；本地 Mock 强制校验 Header，但响应仍使用便于联调的 JSON-RPC JSON。
