# 设备范围后台认证设计

日期：2026-07-28

## 背景

生产环境当前只允许服务器本机或 SSH 隧道访问管理接口。公网打开管理页面时，服务端返回 `403`，因此数据库中的对话和订单仍然存在，但页面无法展示数据。

本次改造需要在保留本机运维通道的同时开放受控的公网后台登录，并让每个下发的授权账号只能查看其绑定设备产生的沟通对话记录。

## 目标

- 提供独立的账号密码登录页。
- 保留服务器本机和 SSH 隧道免登录访问。
- 提供超级管理员 `myjadmin`，可查看全部对话和管理授权账号。
- 普通授权账号只可进入历史对话页面，只能读取其绑定设备的数据。
- 支持一个授权账号绑定一个或多个设备。
- 同一设备同一时间只能绑定一个授权账号。
- 现有无设备归属的历史对话仅超级管理员可见。
- 账号停用或密码重置后，已有会话立即失效。
- 不重建、不清空现有 SQLite 数据库。

## 非目标

- 不开放普通授权账号访问配置、商品、订单、设备调试或小程序调试页面。
- 不实现多级组织、门店或成员权限模型。
- 不允许一个设备同时归属多个普通授权账号。
- 不对现有历史对话进行猜测式设备归属。
- 不把密码、会话 Cookie 或完整认证凭证写入日志。

## 方案选择

采用 SQLite 授权账号和设备绑定模型，不采用环境变量账号映射或设备签名链接。

原因：授权需要持续创建、停用、重置和改绑；数据库模型能够即时收回权限，支持后台管理和完整测试，同时避免每次变更服务器配置或重启服务。

## 身份与权限模型

### 超级管理员

- 默认用户名为 `myjadmin`。
- 可查看全部对话，包括 `device_id` 为空的历史记录。
- 可创建、停用和启用普通授权账号。
- 可重置普通授权账号密码。
- 可绑定或解绑设备。
- 可访问现有全部管理页面和管理接口。

### 普通授权账号

- 只可访问登录、退出、当前身份和历史对话相关页面与接口。
- 对话列表、对话详情、消息、事件和关联订单必须在服务端按绑定设备过滤。
- 请求不属于其设备范围的 `conversation_id` 时返回 `404`，不暴露该记录是否存在。
- 账号被停用、密码重置或设备解绑后，后续请求立即使用最新权限结果。

### 本机运维访问

保留现有 loopback peer 与 `X-Real-IP` 双重判断。本机或 SSH 隧道访问继续免登录，并拥有超级管理员等价权限。公网伪造转发头不得触发本机绕过。

## 数据模型

### `admin_accounts`

- `account_id`：内部稳定 ID。
- `username`：唯一登录名。
- `password_hash`：Argon2id 哈希。
- `role`：`super_admin` 或 `device_viewer`。
- `enabled`：账号是否启用。
- `session_version`：密码重置或强制退出时递增。
- `created_at`、`updated_at`。

### `admin_account_devices`

- `account_id`。
- `device_id`。
- 唯一约束：同一 `device_id` 只能归属一个普通授权账号。
- 外键关联账号和现有 `devices` 表。

### `admin_audit_log`

- `actor_account_id`。
- `action`：创建、启停、重置密码、绑定、解绑。
- `target_account_id`。
- `detail`：不含秘密的结构化摘要。
- `created_at`。

### `conversations`

为现有表增量增加可为空的 `device_id` 字段，并为 `device_id`、最近活动时间补充查询索引。

- 现有记录迁移后保持 `device_id = NULL`，只对超级管理员可见。
- 新浏览器体验页对话保持 `device_id = NULL`。
- 新设备对话在首次创建时写入经过设备认证的 `device_id`。

迁移只允许 `ALTER TABLE`、建新表和建索引，不删除现有表或记录。

## 对话归属边界

设备语音链路已经持有经过设备令牌验证的 `device_id`。写入对话前使用事务执行以下规则：

1. 对话不存在时，同时创建对话并固定 `device_id`。
2. 对话已存在且归属当前设备时允许继续写入。
3. 对话已归属其它设备时拒绝。
4. 对话已存在但 `device_id` 为空时拒绝设备认领，避免猜中旧对话或浏览器对话 ID 后越权绑定。

浏览器文字或语音链路只允许写入 `device_id` 为空的对话，不能写入设备归属对话。

## 登录与会话

### 登录

- `POST /api/admin/auth/login` 接收用户名和密码。
- 登录错误统一返回“账号或密码错误”，不区分账号不存在、密码错误或账号停用。
- 同一来源与用户名组合在 10 分钟内最多失败 5 次，超限返回 `429`。
- 成功后清除对应失败计数。

### 会话 Cookie

- 有效期 8 小时。
- 属性：`HttpOnly`、`Secure`、`SameSite=Strict`。
- Cookie 负载包含账号 ID、角色、过期时间和 `session_version`，使用独立管理会话密钥进行 HMAC 签名。
- 每次受保护请求重新读取账号启用状态、角色、`session_version` 和设备绑定，因此停用、密码重置和改绑立即生效。
- `POST /api/admin/auth/logout` 清除 Cookie。

### 初始超级管理员

提供服务器维护命令，以标准输入接收随机密码并把 Argon2id 哈希写入 SQLite。发布流程在服务器生成高强度随机密码，初始化 `myjadmin`，不把明文写入 `.env`、命令参数、数据库或日志；密码只在发布交付时显示一次。

## 路由授权

- 管理 HTML 页面、管理 API、订单管理 API、诊断和调试命名空间继续属于受保护范围。
- 未登录的 HTML 请求跳转登录页；未登录 API 返回结构化 `401`。
- 普通授权账号只允许历史对话页面和对应只读 API。
- 普通授权账号访问其它管理 HTML 返回历史对话页，访问其它管理 API 返回结构化 `403`。
- 本机运维访问在现有严格来源判断通过后跳过账号校验。
- 体验页、设备接入、健康检查和公开语音链路保持原有可用性。

## 页面设计

### 登录页

- 输入账号和密码。
- 登录成功返回原始管理 URL；普通授权账号最终落到历史对话页。
- 展示统一错误提示和限速提示。
- 不在浏览器存储密码或会话令牌。

### 授权管理页

仅超级管理员可见，提供：

- 授权账号列表和启用状态。
- 创建账号并绑定设备。
- 系统生成初始密码并只显示一次。
- 重置密码并显示一次新密码。
- 启用、停用、绑定和解绑设备。

### 历史对话页

- 超级管理员继续看到全部对话。
- 普通授权账号只看到绑定设备产生的对话。
- 普通授权账号隐藏其它管理菜单，只保留历史对话和退出登录。
- 对话详情继续展示消息、事件和关联订单，但所有数据由服务端授权查询返回。

## 跨站请求防护

- Cookie 使用 `SameSite=Strict`。
- 所有改变账号、密码或设备绑定的请求只接受 JSON。
- 公网状态变更请求校验 `Origin` 与请求主机一致。
- 本机运维请求仍按现有可信来源规则处理。

## 错误处理

- `401 login_required`：未登录或会话过期。
- `403 forbidden`：已登录但角色不允许。
- `404 not_found`：设备范围外的对话或不存在的记录。
- `409 device_already_bound`：设备已绑定其它授权账号。
- `429 login_rate_limited`：登录失败次数超限。
- 所有认证失败日志只记录事件类型、来源摘要和时间，不记录密码、Cookie 或完整请求体。

## 测试策略

### 后端

- 正确和错误登录、统一错误、限速与限速恢复。
- Cookie 签名、过期、篡改、退出、停用和 `session_version` 失效。
- 本机/SSH 隧道绕过保持有效，公网伪造头继续被拒绝。
- 超级管理员可访问全部管理范围。
- 普通授权账号只可访问历史对话。
- 两个账号绑定不同设备后，列表、详情、事件和关联订单完全隔离。
- 请求其它设备的对话返回 `404`。
- 设备不能接管旧的无归属对话，也不能复用其它设备对话 ID。
- 同一设备重复绑定返回 `409`。
- 数据迁移保留旧记录和现有记录数。

### 前端

- 未登录跳转登录页，登录后返回目标页。
- 普通授权账号只显示允许菜单。
- 创建授权、一次性密码展示、重置、停用和设备改绑。
- 登录页、授权管理和历史对话在桌面与手机宽度下无溢出。
- API 返回 `401` 时统一跳转登录，`403` 和 `429` 展示明确提示。

### 发布验收

- 发布前备份 SQLite 数据库、二进制和静态文件。
- 运行 `cargo test`、UI 验收和语音完整性验收。
- 公网验证登录、退出、超级管理员全部对话、普通账号设备隔离和越权 `404`。
- 验证公开健康、体验页和设备配置接口不受影响。
- 记录回滚包路径，不在发布包中包含本地 `.env` 或其它未提交改动。

## 回滚

代码和静态资源可回滚到发布前备份。数据库迁移为增量结构，旧版本会忽略新增表和字段；不需要删除新表或新字段即可运行旧版本。若认证功能异常，先回滚二进制和静态文件，保留数据库与审计记录。
